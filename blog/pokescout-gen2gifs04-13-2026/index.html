PokeScout Baseline Goal

Baseline application goal using AI assistance.

Introduction

Thanks for checking out my first blog post for this project!

I was eager to get started on PokeScout, so I was not focused on documentation during the earliest stages of development. Because of that, not everything has been documented up to this point.

What you see in the GIF is the baseline goal for the project. Most of the application so far was built with ChatGPT assistance while I learned how larger applications are structured, layered, and developed. This helped me understand how different parts of an application work together, from the user interface to the data and API calls behind it.

Now that I have a better understanding of what I want the final project to become, I am going to start recreating PokeScout on my own without AI assistance. From this point forward, the project will focus on my personal learning, development, and ability to build the application myself.

The Beginning

PokeScout started as an idea for a Pokémon discovery app that felt familiar and fun to use. I wanted users to be able to browse Pokémon in a way that reminded them of a Pokédex, while also giving them access to related Pokémon card images.

The current version serves as my reference point. It shows the kind of experience I want to eventually build on my own. Users can browse Pokémon by generation, view animated Pokémon GIFs, and select Pokémon to view related cards.

At first, the application loaded every Pokémon GIF at once. While this worked for testing, I realized it would not scale well as the project grew, especially once deployed to Azure. To improve this, the app now starts by showing the starter Pokémon for each generation. When a user selects a starter, only the Pokémon from that generation are loaded.

This was an important design change because it made the app more efficient and helped me think more carefully about performance, scalability, and user experience.

Moving Forward

This blog post marks the transition point for PokeScout.

Up until now, AI assistance helped me create a working baseline and understand what the project could become. Going forward, I want to use that baseline as a guide while I rebuild and improve the project myself.

My goal is not just to finish the application, but to understand how it works at every level. I want to become more comfortable with the structure of the code, improve the design, make better development decisions, and gain confidence building features without relying on AI to create them for me.

PokeScout is now becoming a learning project first. Each update from here will document what I build, what I learn, what problems I run into, and how I solve them.

For now, the main branch will preserve the AI-assisted baseline, while the dev branch will become the space where I rebuild, experiment, and continue developing the application as part of my learning process.
